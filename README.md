# Lab Activity 3: Object-Oriented Design and Implementation

## Description
This project implements an **Inventory Monitoring System** in Python using Object-Oriented Programming (OOP) principles. It utilizes two main classes (`Item` and `InventoryManager`) to handle record keeping and stock adjustments.

## How to Run

1. Open your terminal or WSL Ubuntu environment.
2. Navigate to the project directory:
   ```bash
   cd lab_activity_3
3. Run the script:
   ```bash
   python3 inventory_system.py
